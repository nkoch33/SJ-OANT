# Evaluation Frameworks

This directory contains the official evaluation frameworks for dialogue performance assessment across three major benchmarks.

## Benchmarks

### MultiWOZ 2.4
**Location**: `multiwoz/`
**Description**: Large-scale multi-domain task-oriented dialogue corpus
**Domains**: Hotel, restaurant, taxi, train, attractions
**Metrics**: Response diversity, relevance, information accuracy, task understanding
**Framework**: Based on [Tomiinek/MultiWOZ_Evaluation](https://github.com/Tomiinek/MultiWOZ_Evaluation)

### Schema-Guided Dialogue (SGD)
**Location**: `sgd/`
**Description**: Comprehensive schema-driven dialogue dataset from DSTC8
**Features**: Multi-service, multi-intent conversations with structured schemas
**Metrics**: BLEU, slot F1, semantic similarity, intent accuracy
**Framework**: Based on [google-research-datasets/dstc8-schema-guided-dialogue](https://github.com/google-research-datasets/dstc8-schema-guided-dialogue)

### Taskmaster
**Location**: `taskmaster/`
**Description**: Realistic conversational dataset from Google Research
**Features**: Human-human and human-assistant dialogue styles
**Metrics**: BLEU, ROUGE, semantic similarity, slot extraction F1
**Framework**: Official Taskmaster evaluation protocol

## Core Components

### `unified_evaluator.py`
Main evaluation orchestrator that:
- Coordinates evaluation across all benchmarks
- Standardizes metric computation
- Manages model configuration and comparison
- Generates comprehensive evaluation reports

### `baseline_evaluator.py`
Baseline system evaluation including:
- Standard LLM evaluation (GPT-3.5, LLaMA-2, Mistral)
- Memory-augmented baseline evaluation
- RAG system comparison
- Performance benchmarking

### `test_rag_baselines.py`
RAG baseline testing framework:
- Simple RAG implementation
- Embedded RAG with dense retrieval
- Performance comparison and analysis
- Baseline result generation

## Evaluation Protocol

### Standardized Process
1. **Dataset Loading**: Load benchmark datasets with train/dev/test splits
2. **Model Configuration**: Set up models with identical parameters
3. **Inference Execution**: Run turn-by-turn dialogue generation
4. **Metric Computation**: Calculate standardized metrics
5. **Report Generation**: Aggregate results with statistical analysis

### Configuration
- **Conversations per Benchmark**: 100 randomly selected from test sets
- **Random Seed**: Fixed at 42 for reproducibility
- **Context Length**: Standardized across all models
- **Inference Budget**: Identical computational resources

## Usage

### Running Individual Benchmarks
```bash
# MultiWOZ evaluation
cd multiwoz
python official_evaluator.py

# SGD evaluation  
cd sgd
python official_evaluator.py

# Taskmaster evaluation
cd taskmaster
python official_evaluator.py
```

### Unified Evaluation
```bash
# Run all benchmarks
python unified_evaluator.py

# Run baseline comparison
python baseline_evaluator.py

# Test RAG baselines
python test_rag_baselines.py
```

## Results

Evaluation results are stored in:
- `rag_baseline_test_results.json`: RAG baseline performance
- Individual benchmark result files in respective directories
- Comprehensive reports generated by unified evaluator
